# Task-to-Game Mapping：装箱，还是放过

> 状态：V1 机制映射冻结；认知阈值不在代码中擅自泛化，具体阈值待负责人批准。

| 任务构件 | 游戏表达 | 保持不变的数据 |
| --- | --- | --- |
| Go 刺激 | 蓝印货物 | 刺激类型、呈现时间、是否响应、反应时 |
| No-Go 刺激 | 红印货物 | 刺激类型、呈现时间、是否抑制、虚报 |
| 响应 | 点击货物或空格装箱 | 单一 primary 输入及单调时间戳 |
| 不响应 | 让货物通过 | 截止时点、正确抑制或遗漏 |
| block | 45 秒装箱轮次 | seed、level、参数版本和所有试次 |

污染检查：

- 颜色与“蓝印/红印”文字同时编码，避免只靠色觉；形状本身不预测 Go/No-Go。
- 点击目标位置固定，不加入移动瞄准、拖拽或额外按键负荷。
- 正误动画发生在判定后，不提供下一试次线索。
- 娱乐分数与命中、遗漏、虚报、反应时分开保存；不输出跨任务脑力总分。
- Go 比例、刺激时长和升级阈值必须通过版本化参数确认，不从竞品曲线照搬。
