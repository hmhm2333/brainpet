# Task-to-Game Mapping：行囊不重样

> 状态：V1 映射冻结；固定容量持续更新，不把它简化成 DCCS 或静态记忆配对。

| 任务构件 | 游戏表达 | 保持不变的数据 |
| --- | --- | --- |
| 初始集合 | 先看见行囊中的 3 件物品 | 初始集合、seed、首次呈现时间 |
| 新项目进入 | 一件新物品进入行囊 | 进入项目、更新时间、更新后集合 |
| 被移出项目 | 两个候选中的正确答案 | 正确候选、位置、作答与反应时 |
| 持续更新 | 每轮都基于上一轮更新后的集合 | 试次顺序和固定容量 |
| block | 45 秒连续行囊更新 | level、参数版本、遗漏和结果 |

污染检查：

- 首轮先呈现初始集合，不能让用户猜一个从未见过的移出项目。
- 候选左右位置由 seed 决定，避免固定按键成为答案线索。
- 新项目、集合槽位和候选使用同一符号集合，不靠额外故事规则判断。
- 只要求更新与识别移出项目，不附加拖放、排序、路线或空间导航负荷。
- 娱乐分数与正确、错误、漏答、每轮反应时分开保存；容量和时限的升降级需版本化。
