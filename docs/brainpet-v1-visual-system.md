# BrainPet V1 角色、视觉与声音规格

> 状态：V1 实现冻结
> 适用版本：Stage asset `1.0.0`；`pack-refresh` asset `1.1.0`

## 角色与训练入口

- BrainPet 不另造一只会替换用户桌宠的固定角色。当前激活的 OpenPets 宠物就是邀请、出题和庆祝角色；舞台从 Host 读取其 spritesheet，读取失败时回退到随包提供的默认像素猫头鹰。
- 训练部位冻结为宠物右侧的黄色 `B` 配件，逻辑点击区 `30×30`。它属于宠物窗口，不是托盘菜单或舞台内网页按钮。
- 点击后宠物与配件共同执行 `480ms`、steps 动画，再展开锚定舞台；完成、连贯和刷新纪录分别触发 `clear / streak / new-best` 配件状态。

## 共享视觉语言

| 用途 | 色值 | 使用边界 |
| --- | --- | --- |
| 主墨色 | `#17243b` | 像素轮廓、标题栏、文字 |
| 深阴影 | `#0d1729` | 硬边投影，不做柔和 SaaS 阴影 |
| 纸张色 | `#fff7dc` | 面板、按钮和高可读文本底 |
| 训练金 | `#f5bd3d` | 入口、进度、主操作和分数牌 |
| 金色阴影 | `#d9952f` | 入口与奖牌内阴影 |
| 天空蓝 | `#70c9e8` | Go 场景、舞台天空 |
| 行囊绿 | `#55aa7b` / `#76ad59` | 持续更新、平台和结算地面 |
| 警示红 | `#d95b66` | No-Go 与错误，不单独承担语义 |

- 宠物、窗口标题栏、`B` 宝石、平台/工作台、行囊/货物轮廓、按钮与结算奖牌共用上述调色板和 2–5px 硬边轮廓。
- 字形道具使用有限的单色集合，由容器、位置、文字和颜色共同表达；Go/No-Go 不允许形状预测答案。
- CSS 与 spritesheet 均使用 `image-rendering: pixelated`；中文正文继续使用系统高可读字体。
- 用户版本不显示 Stage Exerciser、帧诊断面板、默认 HTML 控件或临时占位文字。

## 动作与反馈

| 时点 | 已实现效果 |
| --- | --- |
| 发起 | 宠物预备 + 配件抛出，`480ms` |
| 正确 | 刺激短促提亮、场景文字反馈、660Hz 短音 |
| 错误 | 刺激四步抖动、明确纠正文字、180Hz 短音 |
| 连贯 | HUD 显示 combo，宠物配件进入 `streak` 色态 |
| 升级/结束 | 分数牌 steps 弹入、宠物庆祝帧、880Hz 短音 |
| 新纪录 | `NEW BEST` 与稀有金色配件光圈 |

四类 Stage 音效均由本地 Web Audio 合成，约 `100ms`，无背景音乐、无联网资源，并受统一静音开关控制。降低动画会关闭动画和过渡；高辨识模式提高整体对比度。

## 资产来源与边界

- 默认宠物 spritesheet、缩略图和应用图标继承自本仓库的 OpenPets 来源与许可；用户安装宠物通过既有 `openpets-pet://spritesheet` 只读加载。
- BrainPet 新增舞台、道具、HUD、动画和短音均由本项目代码生成，没有复制竞品角色、贴图、音效或关卡数据。
- Noto Color Emoji 的许可单独保存在 `apps/desktop/assets/NotoColorEmoji.LICENSE.txt`；BrainPet 核心任务不依赖彩色 emoji 作为答案线索。

## 重开美术系统的条件

只有以下情况才扩张资源系统：单场景大量同时活动 sprite、需要 camera/filter/大量粒子、当前 DOM/CSS 无法维持最低 30 FPS 有效节奏，或真实用户证明当前字形道具辨识不足。替换渲染层不得修改 Host、Runtime、Task Contract 与持久化合同。
