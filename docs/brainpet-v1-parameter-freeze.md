# BrainPet V1 参数冻结表

> 状态：工程实现已冻结，待认知任务负责人批准
> 参数版本：Go/No-Go 为 `2.2.0`；持续更新开发模块仍为 `1.1.0`

这份表只陈述当前代码的实际参数，不声称这些阈值具有训练效果或已完成认知学验证。批准后保持版本；任何修改都必须提升 `parameterVersion`，旧版本的每关进度和最高分不与新版本混算。

## 共同结构

- 单局 `45,000ms`，3 个等时 block。
- 关卡范围 1–10；通过后升一级，不通过留在本关。
- 成绩有效需要无失焦污染、无低于 30 FPS 的持续节奏失守，并满足任务通关阈值。
- 同一 seed、关卡和参数向量必须生成同一试次序列。

## 装箱，还是放过

| 参数 | 当前实现 |
| --- | --- |
| 计分试次 | 固定 24：18 Go / 6 No-Go；首题 Go；最多连续 4 Go / 2 No-Go |
| 飞行 / 反应 | 抛出第一帧即开放整个游戏舞台的左键单击与空格输入并开始 RT；飞行时长等于反应窗，到达反应区即截止，无落点停顿 |
| Level 反应窗 | `max(470, 650 - 20 × (level - 1)) ms` |
| 快速 RT 基准 | `220ms` |
| 反馈 / 试次间隔 | `220ms` / seed 决定 `120–160ms` |
| 分数 | Go hit `40–200`；correct No-Go `+40`；false alarm `-40`；Go miss `-20` |
| 暂定通关阈值 | 准确率 `≥75%`、正确数 `≥18`，且 6 个 No-Go 至少正确抑制 5 个 |

当前记录 Go 命中、Go 漏答、No-Go 正确抑制、false alarm、反应时、block、seed 与完整参数向量。抢答概念已随“抛出即呈现”取消；拖动作废账本尚未持久化，需在正式参数批准前补齐。

## 行囊不重样

| 参数 | 当前实现 |
| --- | --- |
| 容量 | `min(5, 3 + floor((level - 1) / 3))` |
| Level 基础反应窗 | `max(1800, 3300 - 110 × (level - 1)) ms` |
| Block 内变化 | 每进入下一个 block 再减少 `140ms`，任务层下限 `1500ms` |
| 候选数 | 固定 2，属于任务骨架而非难度参数 |
| 正确 / 错误娱乐分 | `+140 / -35` |
| 暂定通关阈值 | 准确率 `≥75%` 且正确数 `≥4` |

每轮新物品必须不在上一集合中；两个候选都不出现在更新后集合里，且只有正确候选属于上一集合。由此不能通过对照当前可见行囊绕过持续更新记忆。
